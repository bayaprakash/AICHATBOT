## Read this first (honesty note)
- **Not investment advice.** Names are *research candidates to investigate*, not buy calls.
- Sector numbers come from web searches on 18 Nov 2026. Many are from market-research vendors and news summaries, **not primary reports**; vendors disagree widely. Each number is labelled with its source and a confidence level.
- Company names come from general knowledge of the sector plus search results. **I did not pull live prices, valuations or latest quarterly results.** Every name must pass the checks in file 4 and file 6 before you act. "Early stage" labels are hypotheses to test, not facts.
- Small/micro-cap stocks can fall 50%+ even when the story is right. Size positions accordingly.
